# Criar a app do webserver em Dart
Como um desenvolvedor de aplicações API/Rest, crie 
um aplicação Dart que funciona como um servidor web 
que aceita requisições REST. 
A aplicação irá mockar um banco de dados usando 
uma lista de alunos (id, nome, nota1, nota2, faltas).
A aplicação irá retornar uma chamada REST get de um 
aluno recebendo o seu id e uma outra chamada 
retornado todos os alunos.
